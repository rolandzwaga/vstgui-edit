## Notes

- Spec builds on 008-view-selection which provides selection state management, hit testing, and keyboard handling
- Intersection-based selection chosen over containment-based as the more user-friendly default
- Minimum marquee size (5x5px) prevents accidental deselections from micro-drags
- Pan/zoom cancellation prevents confusing multi-gesture interactions
