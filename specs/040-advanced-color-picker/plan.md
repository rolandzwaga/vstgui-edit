# Implementation Plan: Advanced Color Picker

**Branch**: `040-advanced-color-picker` | **Date**: 2026-01-11 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/040-advanced-color-picker/spec.md`

## Summary

Implement an advanced Color Picker component with visual selection (HSB gradient + hue slider + alpha slider), multiple input formats (HEX/RGB/HSL), color swatches (document + predefined + recent), eyedropper tool, and two usage modes (inline and popup). The picker always outputs 8-digit HEX (#RRGGBBAA) regardless of input mode.

## Key Implementation Notes

### Output Format (FR-009a)

All color selections MUST output 8-digit HEX regardless of input mode:
- RGB input `(255, 85, 0, 128)` -> outputs `#FF5500B0`
- HSL input `(20, 100%, 50%, 50%)` -> outputs `#FF5500B0`
- Document color "Background" -> outputs `"Background"` (name reference preserved)
- Predefined color -> outputs `"~ BlackCColor"` (reference preserved)

### Gradient Area (FR-001)

Standard HSB picker layout:
- X-axis: Saturation 0% (left/gray) to 100% (right/saturated)
- Y-axis: Brightness 100% (top/bright) to 0% (bottom/dark)
- Hue determines base color, selected via separate slider

### Keyboard Navigation (FR-024, FR-025, FR-026)

Arrow keys in gradient/slider:
- Single press: 1% movement
- Shift held: 10% movement

### Recent Colors (FR-013)

localStorage key: `vstgui-edit:recent-colors`
- Max 10 colors (FIFO when full)
- Store as array of 8-digit hex strings
- Graceful degradation if localStorage unavailable

### Invalid Dismiss (FR-022a)

When popup closes with invalid value:
1. Revert to `originalValue` (captured on open)
2. Call `onCancel()` callback
3. Close dropdown
